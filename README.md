# Credit-Risk-Analytics-and-Classification

A machine learning project for predicting customer credit scores into **Poor, Standard, and Good** categories using financial and behavioral data.

### Overview
The project covers data exploration, preprocessing, feature engineering, and model comparison between Random Forest and XGBoost.

### Key Highlights
- Performed EDA and data cleaning, including missing-value handling and outlier treatment.
- Applied categorical encoding and Robust Scaling for model preparation.
- Tuned Random Forest and XGBoost using RandomizedSearchCV.
- XGBoost achieved **75.37% test accuracy** and **0.7346 Macro F1**.
- Analyzed feature importance to identify key factors related to credit scores.

### Technologies
Python, Pandas, NumPy, Scikit-learn, XGBoost, Random Forest
